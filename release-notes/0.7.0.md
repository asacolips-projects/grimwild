## Changes
- Added support for the Community Edition rules. This is now an optional system setting to enable the CE rules and does the following:
  - Adds Desperate to the sheet
  - Bloodied and Rattled only apply thorns to their relevant rolls (physical / mental)
  - Compendium buttons on the character sheet (talents, arcana) will reference their CE equivalent compendiums.
- Added Community Edition compendiums in addition to the original 1.4 compendiums. These can be accessed without enabling the CE system setting. The main compendium that's still missing is monsters, which will be included in a separate release.
- Added Gear tab to the character sheet for mundane gear. This is based on the arcana item type, loosely.
- Added a new edit/view toggle to the top left of the Arcana and Gear item sheets. This improves the presentation of them in play, and will eventually make its way to other sheets.
- Added support for CE optional rules as system settings:
  - Encumbrance (appears in gear and arcana)
  - Supplies (appears in gear)
  - Coins (appears in gear)
  - Vigor (appears in sheet header)
  - Armor (appears in conditions, since it counts as a Lightly Armored or Heavily Armored condition in the rules. Also accounts for Bulwark).
- Added a new `health` attribute to the data model so that tokens can show health on the resource bars. This is automatically calculated and can't be changed directly (0 = dropped, 1 = desperate, 2 = bloodied/rattled, 3 = marked, 4 = no harm, max).
- Updated landing page backdrop to the Community Edition cover art.

## Bug fixes
- Refactored builds to use Vite instead of Gulp and how the Vue sheet renderer works. For the most part, this shouldn't be noticeable during play, but there were a few bugs related to ProseMirror text editors specifically that have been resolved by this change.
